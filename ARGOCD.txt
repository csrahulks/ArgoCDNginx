Create NameSpace :::
Command :
1.>>>>>>kubectl create namespace argocd

:::Change argocd-server from ClusterIP to NodePort:::
Command ::: >>>>>kubectl patch svc argocd-server -n argocd -p "{\"spec\": {\"type\": \"NodePort\"}}"

Port-Forwarding to custom Port 8090
Command  ::::>>>>>> kubectl port-forward svc/argocd-server -n argocd 8090:443 --address 0.0.0.0
